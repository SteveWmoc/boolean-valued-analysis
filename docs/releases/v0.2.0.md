# Boolean-Valued Analysis v0.2.0

**Status:** release notes prepared; publish after the pinned CI and the
independent architecture audit pass and the release-preparation PR is merged.

This is a mathematical API release. It extends the internal-real/spectral-family
correspondence into Hilbert-free spectral arithmetic and delivers the first
application-driven typed ascent/descent interface for Takeuti §1.4.

## Highlights

### Spectral arithmetic (M024)

The existing equivalence between separated internal Dedekind reals and
Boolean spectral families now supports Boolean order, localization, addition,
maximum, boundary-correct negation, absolute value, positivity, localized
estimates, partition-of-unity mixing, and sign-region multiplication. This is
the Hilbert-free part of Takeuti's §1.3 arithmetic; no unbounded self-adjoint
operator realization is claimed.

### Definite sets and internal functions (M025)

- Explicit definite presentations retain Takeuti's displayed domain and
  make every displayed coefficient `⊤`.
- General Kuratowski pairs and extensional map graphs give Boolean-valued
  functionality and evaluation.
- Proposition 1.4.1 realizes extensional displayed maps as internal functions.
- Proposition 1.4.2 is available in both directions: an internal function
  at truth `⊤` determines a **unique** extensional external map into the
  full top-valued member carrier. Different chosen raw representatives yield
  the same separated graph.
- The checked-natural specialization recovers the forward/reverse function
  correspondence on `ω`. Any ordinary `ℕ → InternalReal` sequence has a
  forward internal realization with the correct checked-natural evaluations.

The generic correspondence and the ordinary external-sequence interface
require only `[CompleteBooleanAlgebra 𝔹]`. Collecting the entire canonical
internal-real codomain requires the **local**
`[Small.{u} (SpectralFamily 𝔹)]` instance.

## Deliberate limits

The generic reverse theorem recovers `TopMember` outputs. It does not yet
prove that **every** top-valued member of the canonical real codomain is an
`InternalReal`; a real-typed reverse sequence needs upper-cut closure under
Boolean mixing. M026 operator realization and M027 convergence/Bolzano–
Weierstrass interpretation are outside this release. No global quotient
representative selector or universal typed ascent was added.
